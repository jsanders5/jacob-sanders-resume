\section{Applied AI Engineering}

\begin{itemize}
  \item \textbf{Context engineering:} Builds daily with Claude Code in a structured
        spec/plan/review loop, maintaining repo context files, scoped task specs,
        and documented conventions so coding agents execute reliably across sessions
  \item \textbf{Evaluation harnesses:} Built a leak-free forward-tracking eval harness
        that logs every model call to an immutable ledger and scores live calls
        against realized outcomes (edge, hit-rate, Sharpe, t-stat), separating model
        quality from noise
  \item \textbf{Guardrails \& generated-output safety:} Constrains model output with
        strict whitelists that prevent an LLM stage from overriding a deterministic
        ground-truth classification, and grounds a tutoring assistant so it cannot
        leak solutions; HMAC-verified webhooks, row-level access rules, and
        multi-tenant isolation on the data-handling side
  \item \textbf{LLM application delivery:} Ships production multi-stage LLM pipelines
        on the Claude API: structured JSON extraction, semantic search over
        embeddings, prompt caching, model tiering for cost (88\% run-cost reduction),
        backoff retries, and Sentry observability
  \item \textbf{Customer-facing delivery:} Embeds with clients to scope from scratch
        and ship end-to-end in weeks, translating between non-technical stakeholders
        and the system being built
\end{itemize}
